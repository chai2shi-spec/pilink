# Pilink

> 一款基于 **HarmonyOS** 的 B 站第三方视频播放器：刷推荐、看直播、追动态一站搞定。mpv 高清播放内核，可选扫码 / 短信登录 B 站解锁 1080P+ 与个人云端能力，数据全部保存在设备本地。
>
> A third-party Bilibili video player built natively for HarmonyOS — browse the feed, watch live streams and follow creators in one place. Powered by mpv, with optional QR-code / SMS login for 1080P+ playback and personal cloud features. All data stored locally on device.

## 简介

Pilink 把 B 站的视频消费体验整理成一个纯粹的「看视频」应用：底部**首页 / 动态 / 我的**三个页签，
首页聚合**推荐 / 热门 / 排行榜 / 直播**四大内容流，播放走 **mpv 高清内核**，视频页内置 **AI 总结**。
无需登录即可刷推荐、看直播；也可以**扫码或短信验证码登录** B 站账号（凭据仅存本机），
解锁 1080P+ 清晰度与**收藏夹、观看历史、稍后再看、我的关注**等个人能力。

- **作者**：chai
- **前身**：BiliMusic（B 站第三方音乐播放器，转译自 [HanversionOvO/BiliMusic](https://github.com/HanversionOvO/BiliMusic)），本版本起重构转型为视频播放器
- **运行环境**：HarmonyOS NEXT（API 26）手机 / 平板，适配折叠屏与大屏多列布局

## 功能特性

### 🏠 首页

- **四大内容流**：推荐 / 热门 / 排行榜 / 直播，分类 chips 一键切换、左右滑动切换，上拉无限加载
- **新内容置顶刷新**：启动与下拉刷新自动拉取新内容，置顶呈现、旧内容顺延，不整屏跳变；多源列表落盘缓存，启动先显缓存秒开、后台再刷新
- **条目样式两种**：长条 / 双列卡（16:9 封面，窗口越宽列数越多），设置 → 外观一键切换
- **推荐流多维度筛选**：时长、分区、点赞 / 投币 / 收藏等多条件组合过滤；条目「⋯」菜单支持进入 UP 主页、屏蔽 UP / 关键词
- **直播流**：主播 · 分区 · 人气与「直播中」徽标，支持直播清晰度切换，点击直接进直播间起播

### ▶️ 播放

- **mpv 高清播放引擎**（登录可享 1080P+），原生 `libmpv` 内核，软硬解自适应，HDR 真彩恒软解防花屏
- **弹幕**开关与展示（App gRPC 通道拉取，解析在后台线程，弹幕密集不卡顿）
- **倍速、清晰度切换**：播放页内即时调节；卡顿自动降清晰度，断流自动重连续播一次
- **手势全面可定制**：双击动作、横滑进度、长按加速、竖向滑动、中央播放按钮逐项开关，播放器增强 / YouTube 经典 / Bilibili 经典 / 自定义四套预设一键切换
- **旋转与全屏**：转横自动进全屏、竖屏视频按最大显示面积铺满；视频区上滑进全屏、下滑退出
- **空降助手**（SponsorBlock）：接入小电视空降助手（bsbsb.top）网友共建片段，开场 / 口播等一键跳过，分类可配置
- **断点续播 / 自动连播**：记住每个视频进度，播完自动接下一个（可关）
- **后台播放**：`KEEP_BACKGROUND_RUNNING` 长时任务保活，实况窗（Live View）显示进度与总时长，支持实况窗快进 / 快退
- **返回自动小窗**：退桌面 / 切应用自动转画中画小窗续播（可关）
- **投屏**：视频一键投 DLNA 设备，投播中断开即回本机续播

### 🤖 AI 总结

- 视频页「AI 总结」页签：读取视频字幕，一键生成**一句话结论、内容摘要、章节时间轴（点时间戳跳转）、术语解释与金句摘录**
- 支持 **DeepSeek / 阿里云百炼 / 硅基流动 / 智谱 GLM** 及自定义 OpenAI 兼容接口；API Key 只保存在本机，B 站 Cookie 不会发送
- 附带**字幕原文抽屉**：关键词搜索、点时间戳跳转、当前播放片段自动高亮，支持一键复制

### 📺 视频详情

- **简介 / 评论 / 相关推荐 / AI 总结**多页签左右滑动切换，可设进入视频页默认落点
- **评论浏览与互动**：楼中楼回复、点赞、发表评论，长评论区按需加载滚动顺滑
- **点赞 / 收藏 / 转发**操作行：转发支持系统分享、复制链接、一键转发为 B 站动态
- **多 P 与合集**：分 P 列表当前条高亮、按分 P 断点续播；合集底部面板逐集连看
- **UP 主主页 3.0**：片头式资料头、粉丝 / 投稿数据票根，动态 / 投稿 / 合集 / 系列页签 + 搜索常驻，支持关注 / 取关
- **一镜到底转场**：列表点进视频封面原位起飞铺满播放器，返回原路收回；动态图文与评论贴图看图同款

### 🔍 搜索

- **视频与 UP 主合并搜索**，一次输入双结果
- **搜索历史**与 **B 站热搜**即时可查

### 🔗 链接直达

- 点 B 站视频、番剧、直播、UP 空间链接或 `b23.tv` 短链，系统「打开方式」选 Pilink 即自动跳转对应内容（av 号自动换算、短链自动解析），可在设置开关

### 🌊 动态

- **关注动态流**浏览，新投稿粉色时间与未读圆点标出、停留即自动标记已读
- **图片大图查看**、动态评论浮层原地展开（内容滚过顶部渐显模糊遮罩）
- 点赞 / 转发动态（可附言），可屏蔽带货动态与商品推广评论

### 👤 我的与收藏

- **收藏全新改版**：收藏夹 / 追番 / 追剧 / 合集四页签一站管理，收藏夹支持新建、编辑、删除与排序；支持单夹内与跨全部收藏搜索
- **我的追番 / 我的影视 / 每周必看 / 入站必刷**快捷直达；番剧 / 影视索引页条件筛选浏览
- **稍后再看、观看历史、我的关注、消息中心**（回复我的 / @我 / 收到的赞 / 系统通知）一站直达
- 「显示年度大会员徽标」开关：我的页用户卡金渐变装饰（纯本机，不改变真实会籍）

### 👤 账户（可选登录）

- **扫码登录**：B 站官方 passport 二维码流程
- **短信验证码登录**：手机号 + 验证码
- 登录凭据（SESSDATA 等）**只保存在本机**，不上传任何第三方服务器
- 登录后能力：**收藏夹、观看历史、稍后再看、我的关注、动态互动**一站直达
- 不登录可正常使用推荐 / 排行榜 / 直播等匿名功能，随时可退出登录并清除凭据

### 🎨 体验

- **底栏沉浸光感悬浮胶囊**：HDS（HarmonyOS Design System）`HdsTabs` 沉浸材质，页签与内容融合
- **主题色 8 色切换** + 深浅模式跟随，全站组件即时变色
- **应用图标切换**：默认字标与新小电视图标一键切换（系统 API 26 起）
- **What's New 更新弹窗**：新版本首次启动自动展示更新内容，「查看更新日志」随时回看
- **播放报错日志**：播放内核错误 / 降档留痕（200 条环形缓冲），整页或单条复制反馈问题
- **大屏多列布局适配**：平板 / 折叠屏展开态多列网格与双栏适配

## 构建与运行

### 前置条件

- [DevEco Studio](https://developer.huawei.com/consumer/cn/deveco-studio/)（含 HarmonyOS SDK）
- 一台 HarmonyOS NEXT 手机 / 平板（或模拟器）

### 用 DevEco Studio

1. `Git Clone` 本仓库，在 DevEco Studio 中打开**仓库根目录**（含 `entry` 模块与 `build-profile.json5`）
2. 等待 `oh-package` 依赖同步完成（播放内核 `libmpv_napi` 随仓库内置，无需额外配置）
3. `Build → Build Hap(s) / APP(s)` 生成 HAP
4. **真机安装需在 `Project Structure → Signing Configs` 配置签名**（未签名只能产出 `entry-default-unsigned.hap`）

### 命令行（Hvigor）

```bash
hvigorw assembleHap --mode module -p product=default --no-daemon
```

> 注：命令行产物默认未签名，真机安装仍需在 DevEco Studio 中配置签名。

## 使用说明

- 底部三个页签：**首页**（推荐 / 热门 / 排行榜 / 直播）、**动态**（关注动态流，需登录）、**我的**
- **登录**（可选）：我的页头像区扫码或短信验证码登录，解锁收藏夹 / 观看历史 / 稍后再看 / 我的关注 / 动态互动
- **AI 总结**：视频页「AI 总结」页签，先「读取字幕」再「生成 AI 总结」；需在设置 → AI 总结配置服务商与 API Key
- **空降助手**：设置 → 空降助手，配置跳过分类（片段数据来自小电视空降助手网友共建）
- **手势定制**：设置 → 播放 → 手势与操控，双击 / 长按 / 竖滑逐项配置，四套预设一键套用
- **链接直达**：系统「打开方式」选 Pilink 打开 B 站链接自动跳转（设置 → 通用可关）
- **外观设置**：主题（深浅）、主题色（8 色）、底栏宽度与滚动隐藏、首页条目样式（长条 / 双列卡）
- **播放控制**（弹幕 / 倍速 / 清晰度 / 手势等）都在播放页内，评论 / 相关推荐 / AI 总结在视频详情页
- **报错记录**：播放失败时先看这里，可整页或单条复制用于反馈
- 新版本首次启动会自动弹出更新内容弹窗，也可在「查看更新日志」随时回看
